Sibank-Listen für den EDUCA‑Import umwandeln

sibank2educa liest die Schüler- und Lehrerexporte aus Sibank und erzeugt daraus die CSV-Datei, die EDUCA für den Import erwartet. Ohne Installation, direkt auf dem Schulrechner.

sibank2educa.exe herunterladen Alle Versionen

Für Windows 10 und 11. Mit Python läuft das Tool auch unter macOS und Linux.

Das Tool befindet sich in der Testphase. sibank2educa ist ein privates Projekt, das den Umstieg auf ein neues Zeugnisprogramm erleichtern soll. Es ist nicht im Auftrag einer Schule entstanden. Prüfen Sie die erzeugten Dateien vor dem Import bitte sorgfältig.

Was das Tool übernimmt

Schüler und Lehrer in einem Durchgang
Beide Sibank-Exporte laden und wahlweise in einer gemeinsamen oder in zwei getrennten Dateien speichern.
Oberstufe ausblenden
Die Jahrgänge 11 bis 13 werden standardmäßig weggelassen. Ein Häkchen nimmt sie wieder mit auf.
Nach Klassen sortiert
Die Schüler stehen in der Reihenfolge 05a, 05b, 06a … und innerhalb der Klasse alphabetisch. Die Lehrer folgen nach Namen sortiert.
Vorschau vor dem Speichern
Die fertigen Datensätze erscheinen als Tabelle. Jede Änderung an den Einstellungen ist sofort sichtbar.
Warnungen bei Unstimmigkeiten
Ungültige Daten, fehlende Klassen oder doppelte IDs werden mit Zeilennummer und Namen gemeldet.
Merkt sich Ihre Schule
Schulnummer und Zielordner sind beim nächsten Start schon eingetragen. Das Schuljahr stellt sich jeweils zum 1. August um.

So kommen die Daten nach EDUCA

  1. Listen in Sibank anlegenEinmalig je eine Liste für Schüler und Lehrer im Listengenerator erstellen, wie unten beschrieben.
  2. Listen als CSV exportierenDie beiden Listen aus Sibank als CSV-Dateien speichern.
  3. sibank2educa startenDie Schüler- und die Lehrerdatei öffnen, Schulnummer und Schuljahr prüfen und die Vorschau kontrollieren.
  4. Konvertieren und importierenAuf „Konvertieren“ klicken und die erzeugte Datei in EDUCA importieren.

Listen im Sibank-Listengenerator anlegen

Die beiden Exporte entstehen über den Listengenerator in Sibank. Legen Sie dort einmalig je eine neue Liste an und wählen Sie auf dem Reiter „Felder“ die Felder genau in dieser Reihenfolge aus. Die Spaltenüberschriften entsprechen jeweils dem Feldnamen.

Groß- und Kleinschreibung der Überschriften spielt keine Rolle. Trennzeichen (Komma oder Semikolon) und Zeichenkodierung erkennt das Tool selbst.

Was in der Zieldatei steht

Der Dateiname entsteht automatisch. Er zeigt auf einen Blick, für welche Schule, welches Schuljahr und welche Personengruppe die Datei erstellt wurde und wann.

Datenschutz

sibank2educa arbeitet ausschließlich auf dem Rechner, auf dem es gestartet wird. Es baut keine Internetverbindung auf und überträgt keine Daten. Die erzeugten Dateien landen nur in dem Ordner, den Sie auswählen.

Diese Website lädt keine externen Schriften, Skripte oder Bilder und setzt keine Cookies.

Echte Exportdateien gehören nicht ins Netz. Laden Sie Sibank-Exporte und erzeugte Importdateien nicht bei GitHub oder anderen Diensten hoch, auch nicht zum Melden eines Fehlers. Beschreiben Sie Probleme stattdessen mit erfundenen Beispieldaten.

Häufige Fragen

Windows zeigt beim Start eine Warnung. Ist das normal?

Ja. Die EXE ist nicht kostenpflichtig signiert, deshalb meldet Windows SmartScreen beim ersten Start eine unbekannte App. Klicken Sie auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“. Der vollständige Quellcode ist auf GitHub einsehbar.

Muss Python installiert sein?

Für die EXE nicht. Wer lieber das Python-Skript nutzt, braucht Python 3.8 oder neuer von python.org. Zusätzliche Pakete sind nicht nötig.

Warum fehlen die Klassen 11 bis 13 in der Zieldatei?

Das Häkchen „Oberstufe ausschließen“ ist beim Start gesetzt. Entfernen Sie es, werden alle Jahrgänge übernommen.

Kann ich Schüler und Lehrer getrennt exportieren?

Ja. Entfernen Sie das Häkchen „Schüler und Lehrer in einer Datei zusammenfügen“. Dann entstehen zwei Dateien mit SuS beziehungsweise LuL im Namen. Sie können auch nur eine der beiden Exportdateien laden.

Wo speichert das Tool seine Einstellungen?

In der Datei .sibank2educa.json in Ihrem Benutzerordner (%USERPROFILE%). Gespeichert werden nur Schulnummer, Zielordner, Kodierung und die Einstellung zum Geburtsort, keine Schülerdaten.

Funktioniert es auch mit anderen Schulverwaltungsprogrammen?

Nur wenn deren Export dieselben Spalten enthält wie die oben beschriebenen Sibank-Listen. Die Spaltennamen müssen passen, die Reihenfolge ist egal.
