# Datenschutz

- sibank2educa verarbeitet Schüler- und Lehrerdaten **ausschließlich lokal** auf dem Rechner, auf dem es ausgeführt wird. Es werden keine Daten ins Internet übertragen.
- Gespeichert wird außer den erzeugten CSV-Dateien nur die Einstellungsdatei `%USERPROFILE%\.sibank2educa.json` (Schulnummer, Zielordner, Kodierung, Geburtsort-Option). Sie enthält keine personenbezogenen Daten.
- Export- und Importdateien enthalten personenbezogene Daten. Sie sollten nach dem Import in EDUCA gelöscht oder sicher abgelegt werden.
- **Echte Export- oder Importdateien niemals in das Repository, in Issues oder in das Wiki hochladen.** Die `.gitignore` schließt deshalb alle `.csv`-Dateien außerhalb von `beispiele/` aus.
- Die Beispieldateien im Repository enthalten ausschließlich erfundene Personen.

Hinweise zur Projektwebsite stehen im [Impressum](https://lutherschule30167.github.io/sibank2educa/impressum.html).
